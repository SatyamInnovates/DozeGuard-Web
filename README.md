This is the website of my tool named DozeGuard!!

DozeGuard is a Linux desktop application that keeps your computer awake whenever you want.

Is is mainly desgined for long running tasks so you can do other stuff or be while your ai agents work or a game downloads!

## 💻 Run Locally

Want to explore or work on the website?

1. Clone the repository:

```bash
git clone https://github.com/SatyamInnovates/DozeGuard-Web.git
```

2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click inside the HTML file and select **Open with Live Server**.
5. The website will open in your browser automatically.



You can see the actual repo: (https://github.com/SatyamInnovates/DozeGuard/)
