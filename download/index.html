02 / INSTALLATION

Let's install

Installation instructions for each Distro

Debian / Ubuntu

You can use .deb for any debian-based linux distros

After downloading the DEB package, open a terminal in its download folder:

Run below command from terminal
sudo apt install ./dozeguard.deb

Fedora

Install the downloaded RPM package:

Run below command from terminal
sudo dnf install ./dozeguard.rpm

Arch Linux

Install the downloaded package:

Run below command from terminal
sudo pacman -U ./dozeguard.pkg.tar.zst
